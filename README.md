# Yarrowpine Admin Dashboard Kit

*A responsive admin dashboard starter for React® + Vite® + TypeScript — free edition*

Free edition: dashboard page (KPI cards, SVG revenue chart, traffic sources, recent orders), a users table with
search, filter, sort and pagination, responsive sidebar and 404 page, with 11 Vitest tests. Demo brand: YourBrand.

```bash
npm install
npm run dev
npm run check      # typecheck + lint + tests + build
```

## Pro edition
Yarrowpine Admin Dashboard Kit Pro adds orders, settings and sign-in pages, a dark-mode toggle, CSV export wired into the tables, a customization guide and more tests. Available on our Gumroad store.
